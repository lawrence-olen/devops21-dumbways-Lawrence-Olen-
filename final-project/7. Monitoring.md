## PromQL syntaks

- CPU Usage
  Query ini digunakan untuk menghitung penggunaan CPU pada seluruh instance selama 5 menit terakhir. Hasil akhir dikalikan 100 untuk mendapatkan persentase.

  ```
  sum(rate(node_cpu_seconds_total{mode!="idle"}[5m])) by (instance,node) / sum(rate(node_cpu_seconds_total{}[5m])) by (instance,node) * 100
  ```

- RAM Usage
  Query ini digunakan untuk menghitung persentase memori yang tersedia di setiap instance dalam sistem dan persentase menunjukkan berapa banyak memori yang tidak / sudah digunakan.
  
  ```
  (sum(node_memory_MemAvailable_bytes) by (instance) / sum(node_memory_MemTotal_bytes) by (instance)) * 100
  ```

- Free Storage
  Query ini digunakan untuk menghitung persentase runag penyimpanan yang tersedia pada file system di setiap instance.

  ```
  sum(node_filesystem_avail_bytes{fstype!="tmpfs", fstype!="rootfs"}) by (instance) / sum(node_filesystem_size_bytes{fstype!="tmpfs", fstype!="rootfs"}) by (instance) * 100
  ```

- Network I/O (Nginx Monitoring)
  Query ini digunakan untuk menghitung total data jaringan yang diterima dan dikirim berdasarkan data dari IP yang sudah ditentukan.

  ```
  (sum(rate(node_network_receive_bytes_total{instance="34.101.180.119:9100"}[5m])) by (instance, device) +
  sum(rate(node_network_transmit_bytes_total{instance="34.101.180.119:9100"}[5m])) by (instance, device)) / (1024 * 1024)
  ```
