# Provisioning

**Requirements**
- Local machine w/ Ansible & Terraform
- Biznet GIO NEO Lite Servers
  - Appserver - 2 CPU, 2GB RAM
  - Gateway - 1 CPU, 1GB RAM
-  Others Servers if required

**Instructions**
- Attach SSH keys & IP configuration to all VMs
- Server Configuration using Ansible

# Terraform

1. Buatlah akun Google Cloud Provider (GCP) untuk kebutuhan server kita.

2. Membuat IAM & Admin pada GCP

3. Setup Arsitektur menggunakan Terraform
   **providers.tf**

   **variables.tf**

   **terraform.tfvars**

   **main.tf**


   Cara mengjalankan konfigurasi terraform
   ```
    terraform init
    terraform validate
    terraform plan
    terraform apply

    **Delete
    terraform destroy
   ```

4. Check pada GCP apakah seluruh server sudah terbuat atau belum
