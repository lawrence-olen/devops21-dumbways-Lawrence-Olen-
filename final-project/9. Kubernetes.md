# Installasi K3S untuk master dan worker

Disini saya menggunakan IaC (Ansible) untuk melakukan installasi K3S.

- k3s master

```
- name: "Install k3s on node master"
  shell: curl -sfL https://get.k3s.io | sh -
  
- name: "Fetch k3s token on node master"
  shell: cat /var/lib/rancher/k3s/server/node-token
  register: master_token
  changed_when: false

- name: "Get master node IP and Token"
  set_fact:
    master_ip: "{{ ansible_host }}"
    k3s_token: "{{ master_token.stdout }}"
```

- k3s-agent worker

```
- name: "Install k3s agent on node worker"
  shell: |
    K3S_URL="https://{{ hostvars['master'].master_ip }}:6443"
    K3S_TOKEN="{{ hostvars['master'].k3s_token }}"
    curl -sfL https://get.k3s.io | K3S_URL=$K3S_URL K3S_TOKEN=$K3S_TOKEN sh -
```

# Install Helm dan Setup Ingress Nginx

```
# Install Helm
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

# Verfikasi installasi helm
helm version

# Tambahkan repository ingress nginx
helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx
helm repo update

# Install Ingress Nginx menggunakan helm
helm install ingress-nginx ingress-nginx/ingress-nginx -n ingress-nginx

# Verifikasi installasi Ingress Nginx
kubectl get pods -n ingress-nginx
```

# Deployment Apps 

## Database Deployment
- Membuat Persistent Volume dan Persistent Volume Claim untuk menyediakan penyimpanan data yang persistent

```
apiVersion: v1
kind: PersistentVolume
metadata:
  name: postgres-volume
  namespace: your_namespace
spec:
  capacity:
    storage: 5Gi
  accessModes:
    - ReadWriteOnce
  hostPath:  
    path: /data/postgresql

---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: postgres-volume-claim
  namespace: your_namespace
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 5Gi
```

- Membuat secret untuk menampung environment variabel database

```
apiVersion: v1
kind: Secret
metadata:
  name: postgres-secret
  namespace: your_namespace
data:
  POSTGRES_DB: your_db
  POSTGRES_USER: your_user
  POSTGRES_PASSWORD: your_password
type: Opaque
```

- Membuat file database StatefulSet
```
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: postgres
  namespace: your_namespace
spec:
  serviceName: "postgres"
  replicas: 1
  selector:
    matchLabels:
      app: postgres
  template:
    metadata:
      labels:
        app: postgres
    spec:
      # terminationGracePeriodSeconds: 10
      containers:
        - name: postgres
          image: postgres:14
          imagePullPolicy: IfNotPresent
          ports:
            - containerPort: 5432
          envFrom:
            - secretRef:

            - name: postgres-data

      - name: postgres-data

---

  namespace: your_namespace

    app: postgres

    targetPort: 5432
  type: ClusterIP
```

## Backend Deployment

- Membuat file Deployment untuk Backend

```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: backend
  namespace: your_namespace
spec:
  replicas: 2
  selector:
    matchLabels:
      app: backend
  template:
    metadata:
      labels:
        app: backend
    spec:
      containers:
        - name: backend
          image: your_registry/be-dumbmerch:production2
          ports:
            - containerPort: 5000

---
apiVersion: v1
kind: Service
metadata:
  name: backend
  namespace: your_namespace

  selector:
    app: backend
  ports:
    - protocol: TCP
      port: 5000
      targetPort: 5000
```

## Ingress Nginx untuk Service Backend dan Frontend

```
---
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: ingress-frontend
  namespace: dumbmerch
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
    cert-manager.io/issuer: letsencrypt-prod
spec:
  ingressClassName: nginx
  rules:
    - host: olen.studentdumbways.my.id
      http:
        paths:
        - pathType: Prefix
          path: "/"
          backend:
            service:
              name: frontend
              port: 
                number: 80
  tls:
    - hosts:
        - olen.studentdumbways.my.id
      secretName: wildcard-tls-secret
```
